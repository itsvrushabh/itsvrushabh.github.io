About Me

Hi! I'm Vrushabh Deshmukh — a backend developer and systems builder based in India.

Background & Engineering Focus

I focus on building reliable, distributed, and high-performance server architectures. My day-to-day work spans designing type-safe REST & gRPC APIs, optimizing PostgreSQL and Redis queries, coordinating asynchronous tasks with RabbitMQ, and deploying lightweight containerized services.

I am particularly interested in the intersection of compile-time systems programming (Rust) and high-productivity backend development (Python / FastAPI). I believe that software should be fast by default, defensively designed against failure, and simple to reason about.

Architecture Principles

  • Defensive Concurrency: Embracing async runtimes (Tokio, uvloop) while rigorously guarding shared state and avoiding unbounded in-memory queues.
  • Idempotency by Design: Treating every external webhook and message bus event as potentially duplicated; implementing atomic distributed locks and transaction outboxes.
  • Zero-Fluff Tooling: Minimal dependencies, explicit data models with Pydantic / Serde, and strict static analysis.
  • Observability First: Structured JSON logging, tracing spans, and health checks built into services from day one.
